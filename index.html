Ejemplos de lógica

Desplegables con fragmentos comentados: qué hace el código y por qué.

01 DOM, localStorage, BOM y ventanas

Script de interfaz que persiste preferencias de usuario, personaliza la experiencia según la hora, consulta el BOM (navigator, screen), genera listas dinámicas y abre una ventana de ayuda con postMessage.

  • Recuperación de nombre y color desde localStorage.
  • Saludo contextual (mañana / tarde / noche) con fecha localizada.
  • Eventos input para guardar preferencias al instante.
  • Función documentada con JSDoc que rellena la lista con datos del navegador.
  • Comunicación entre ventanas: window.open + postMessage retardado.
JavaScript
02 API REST con Node.js y Express

Servidor Express con CORS, JSON y SQLite: validación fiscal española, registro de clientes, cálculo de simulaciones en backend e historial por cliente.

  • Middleware express.json y cors para API consumible desde frontend.
  • Validación de DNI, NIE y CIF antes de persistir clientes en España.
  • POST /customers: idempotencia por tax_id (recuperar o crear).
  • POST /simulations: pricing por tramos, IVA 21 % y conversión de divisa validada en servidor.
  • GET /simulations/customer/:id: historial ordenado desde la base de datos.
Node.js · Express
03 Login seguro con PHP y sesiones

Autenticación en servidor con PDO preparado, CSRF, límites anti fuerza bruta, mitigación de timing attacks y redirecciones seguras tras el login.

  • Token CSRF obligatorio en POST antes de validar credenciales.
  • Rate limiting por IP y email (ventana 5 min) para CG-NAT y password spraying.
  • password_verify con hash dummy si el usuario no existe (tiempo constante).
  • session_regenerate_id y comprobación de cuenta activa / email verificado.
  • Anti open redirect: solo rutas relativas internas en redirect_after_login.
PHP · MySQL
